# STARFORGE Dungeon Run Beta Reports

Use this folder for beta QA reports and reproduction bundles.

## Report Files

- Human-readable report: `qa-run-YYYY-MM-DD.md`
- Machine-readable bug list: `qa-run-YYYY-MM-DD.json`
- Optional evidence: screenshots, videos, or copied feedback JSON from the in-game `Copy Feedback` button.

## Minimum Repro Payload

Every actionable beta report should include:

- Build version.
- Seed.
- Faction.
- Ascension.
- Current act and phase.
- Expected result.
- Actual result.
- Steps to reproduce.
- Feedback JSON copied from the run-end screen or debug panel.

Use `qa-run-template.md` and `qa-run-template.json` as the starting point.
