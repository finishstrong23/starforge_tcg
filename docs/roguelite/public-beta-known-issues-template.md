## Severity Guide

- Critical: crash, save corruption, blocker, or run cannot continue.
- High: wrong game logic, broken rewards, broken privacy setting, or unfair player loss.
- Medium: confusing UI, missing preview, unclear feedback, or non-blocking bad state.
- Low: copy, layout, polish, or minor visual issue.

## Release Note Rule

Every critical or high issue must appear in the public changelog before the build link goes out.
