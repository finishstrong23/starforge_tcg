# Dungeon Mode UI Mockups

Drop layout sketches, screenshots, annotated wireframes, etc. here. These
files are reference only — they're **not** bundled into the game build.

Suggested naming: `<area>-<variant>.<ext>` so they sort sensibly.
Examples:
- `combat-layout-v1.png`
- `combat-layout-v2-status-bar.png`
- `map-view-revised.png`
- `hand-zoom-mobile.png`
- `reward-screen-3-options.png`

If a mockup is the source of truth for an active design discussion, link it
from the relevant `phase-*.md` summary so future contributors can find it.
